# Multi-Platform Social Media Engagement Analysis

## Project Overview
This project analyzes social media engagement data across multiple platforms using Power BI. The dashboard helps explore engagement patterns, content performance, platform comparison, and trends over time.

## Platforms Analyzed
- Instagram
- Facebook
- YouTube
- X (Twitter)

## Tools & Technologies
- Microsoft Power BI
- Data Visualization
- Data Analysis
- CSV Datasets

## Dashboard Features
- Social media performance overview
- Platform-wise engagement analysis
- Content type performance comparison
- Engagement trends over time
- Likes, comments, shares, and views analysis

## Project Objectives
- Compare engagement across social media platforms
- Identify content performance patterns
- Analyze audience engagement metrics
- Understand trends using interactive dashboards

- Power BI Dashboard (.pbix)
- Dataset files (.csv)
- Dashboard screenshots
